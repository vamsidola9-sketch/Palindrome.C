Palindrome Checker
This program reverses a number and compares it with the original to check if it is a palindrome.
Great example of loops and number manipulation.
What does it does....
This c program checks whether a given number is palindrome or not.
it reverses the digits of the numbers and compares it with the original value.
  What does it does
  .Takes a number as input 
  .Reverses the number using while loop
  .Compares original and reversed values.
  .Displays whether it is a palindrome or not
  Concepts used
  .Loops(While)
  .Conditional statements(if-else)
